## 为什么作废

这批探针的实现顺序是：

```python
feats_ss = subject_standardize(feats, grp)   # ① 用【全部】窗口拟合 μ/σ
for tr, va in GroupKFold(...).split(...):    # ② 然后才划分
    train / eval                             # ③ 在【同一批】窗口上评估
```

被评估的那个被试，它的 μ/σ 是用**它自己全部窗口**算出来的，
而评估也在同一批窗口上做 → **评估窗参与了归一化统计量的估计**。

打个比方：**用考卷答案算"个性化参数"，再用这份考卷打分。**

结果就是「被试级标准化」的收益被**系统性高估**。这批数字全部不可引用。

> 正确做法见 `scripts/probes/_subject_calibration.py`：
> ① 每个被试**只用静息段最靠前的 30 个窗口**拟合 μ/σ →
> ② 应用到该被试所有窗口 → ③ 训练与评估**只使用非校准窗**（R2）。
