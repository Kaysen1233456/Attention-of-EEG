## A 组：旧 Gen4 的 7 个缺陷

> 来源：`GEN5_PROTOCOL.md`。这 7 条是"知道自己错在哪"的原始记录，**永久保留**。
> 全部在 Gen5 中修复，但每一条都对应一类通用陷阱，换模型后仍可能重犯。

| ID | 缺陷 | 通用陷阱（换模型后仍会犯的版本） | 状态 |
|---|---|---|---|
| **A1** | 微调阶段没有复用预训练阶段的 train-subject normalization | 训练/推理两阶段用不同的归一化统计量 → 训练分布与推理分布不一致，验证集虚高 | 🟡 已修复 |
| **A2** | 阈值搜索把 logit 当作 probability 使用 | 在未过 softmax/sigmoid 的输出上扫阈值 → 阈值含义完全错误，BA 无意义 | 🟡 已修复 |
| **A3** | 阈值来自最后一轮验证结果，而不是最佳 checkpoint | 阈值与模型权重不对应 → 报出的 BA 是"最好权重 + 最差阈值"的错配 | 🟡 已修复 |
| **A4** | checkpoint 依据 AUC 选择，与主协议的 balanced accuracy 不一致 | 选择指标 ≠ 报告指标 → 选出的模型不是报告口径下的最优 | 🟡 已修复 |
| **A5** | 预训练 decoder 与分类 decoder 维度不同，却用 strict load | 迁移时静默失败或直接报错；维度不匹配的参数被误加载 | 🟡 已修复 |
| **A6** | 心算数据使用了不合理的左右通道分组、差值和乘积特征 | 把为**双耳**数据（Ear-SAAD）设计的外科手术式特征，硬套到**头皮** 8 通道上 → 无生理意义 | 🟡 已修复 |
| **A7** | 模型容易利用整体振幅差异：验证被试有效，测试被试失效 | **最危险的一条**：模型学到的是"哪个被试/哪次录制"而不是"什么认知状态"，在开发集上表现良好，一换被试就崩 | 🟡 已修复（改用窗口级 z-score） |

### A7 的强化说明

A7 的机制值得单独记住：当每类数据来自**一段连续录制**时，任何慢变因素
（电极阻抗、被试困倦度、时间点、体位、汗液）都会成为**完美的类别预测因子**。
模型会优先利用这个捷径，因为它在训练集上几乎 100% 可分。
**判断方法**：做"标签打乱"零假设对照。若打乱后 BA 明显 > 0.50，说明存在捷径。

## C 组：2026-10-09 本次审查实测新增

| ID | 做法 | 为什么有害 | 证据 | 等级 |
|---|---|---|---|---|
| **C1** | **用单 seed 的 8 折 CV 值代表教师水平** | 单 seed 会挑到"运气好的那次"，把噪声当成能力。多 seed 后回落到真实水平 | Teacher B v2：**单 seed 42 = 0.7166**（项目记录），**3 seed 均值 = 0.6991** → 乐观偏差 **+1.8 分** | 🔴 禁用 |
| **C2** | **同架构多 seed 软投票集成** | 同架构同数据的 seed 间高度相关，误差不独立，集成的方差削减收益趋近于 0 | **重测（RV-1 修复后）**：Gen5 + 被试级标准化 单 seed **0.7263** vs 3 seed 集成 **0.7175**（**仍没提升，−0.9 分**）。结论不变；原引用的 0.7440/0.7344 来自 C10 泄漏探针，已作废 | 🔴 禁用 |
| **C3** | **靠堆模型参数提升教师** | 数据量/域偏移是瓶颈时，容量 scaling 会饱和；多出的参数只拟合被试特异性噪声 | **重测（RV-1 修复后，同一评估集 2890 窗）**：Gen5 **8,418** 参数 → BA **0.7232**；Teacher B **193,202** 参数 → BA **0.7130**。**23 倍参数，学生反而高 1.0 分** | 🔴 禁用 |
| **C4** | **跨被试任务在时序分支使用 `BatchNorm1d`** | BN 用 batch 内统计量归一化，而 batch 混合了不同被试 → 引入被试间耦合；推理时用 running stats 又与训练不一致。小样本跨被试场景应改用 LayerNorm / GroupNorm | `TeacherB` 的 3 个时序分支、`SpectralCNN` 的时序分支均使用 BN；而 `NBACK_REVISED_ROADMAP.md` 自己写过"避免在 12 个训练被试上依赖 BatchNorm 的被试统计量" → **内部不一致** | 🟠 慎用 |
| **C5** | **跨设置比较模型优劣** | 两个模型如果在不同数据量/不同划分/不同预处理下评估，差距里混入了协议差异，无法归因给模型 | Teacher B 0.7166 vs Gen5 0.6734（项目记录，跨设置）→ 换成**同一时长匹配集**后：Teacher B **0.6899**、Gen5 **0.6956**，**学生反超**（重测值，RV-1 修复后） | 🔴 禁用 |
| **C6** | **用验证集选最佳 epoch 后，再报验证分数** | 同一批数据既做选择又做评估 → 乐观偏差。这是"没有嵌套 CV"时的系统性偏差 | 标签打乱零假设对照：理论应为 0.500，实测 **0.5252** → 偏差约 **+0.025** | 🟠 慎用 |
| **C7** | **用 4 个被试的测试集做结构/超参决策** | 4 个被试的 BA 标准误约 ±5~8 分；任何 <5 分的差异都在噪声里 | 项目测试集 = Subject20/07/14/28，共 488 窗口 | 🟠 慎用 |
| **C8** | **在"标签按整段录制分配"的数据上做窗口级随机划分** | 同一被试的连续窗口高度相关，随机划分会让同一段录制同时出现在训练和测试 → 严重泄漏 | 当前数据每个被试只有 2 段（rest 91 窗 / focus 31 窗），**绝不能随机打散窗口**；必须 subject-disjoint | 🟠 慎用 |

| **C10** | **在 `GroupKFold` 划分之前做被试级标准化** | 统计量用到了**测试折**的数据 → 测试信息泄漏进训练侧 → 校准收益被系统性高估。正确顺序：**先划分 → 只在训练折内拟合统计量 → 再 apply 到评估折** | `scripts/probes/{cnn_domain_probe,domain_probe,matrix_probe,teacherB_probe}.py` 均在 `GroupKFold` **之前**调用 `subject_standardize(feats, grp)`（行 178 / 125 / 113 / 184）。→ **本表 D1 的证据因此不可引用** | 🔴 禁用（🟡 代码已修复） |
| **C11** | **用 30 个校准窗口对 40 维特征做全协方差白化（whitening）** | 样本数 < 特征维数 → 协方差矩阵奇异，白化在数学上不可行，强行求逆只会放大噪声 | 实测 `matrix_rank(cov) = 29 < 40`，条件数 `3.8e18`。只允许**对角**标准化 `(f-μ)/(σ+ε)`（实测对角 σ 范围 0.24–0.61，安全）。已写入 `CALIBRATION_PROTOCOL.md` §1.3 | 🔴 禁用 |

## E 组：标记规范（如何给未来的实验打标签）

每个新实验的 `config.yaml` 与结果 `results.json` 建议加入：

```yaml
# 是否触碰本登记册中的禁用项
registry_check:
  uses_disabled_method: false        # 必须为 false，否则不得启动
  disabled_ids: []                   # 若为 true，列出 ID
  cautious_ids: [C4]                 # 用到的慎用项，必须写理由
  rationale: "BatchNorm 在时序分支保留，因本次不改变架构以保持单因素对照"
```

结果 JSON 中建议加入：

```json
{
  "registry_compliance": {
    "seeds_used": [42, 43, 44],
    "single_seed_only": false,
    "comparison_baseline_protocol": "identical",
    "null_control_run": true,
    "test_subjects": 4,
    "notes": ""
  }
}
```

**硬规则**：
1. 任何报告出来的模型结论，若 `single_seed_only = true`，**不得**与多 seed 结果并列比较。
2. 任何"模型 A 优于模型 B"的声明，必须满足 `comparison_baseline_protocol = identical`。
3. 教师/学生的最终结论必须带 `null_control_run = true`。
