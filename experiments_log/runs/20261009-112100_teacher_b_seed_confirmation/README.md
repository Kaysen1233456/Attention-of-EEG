## 关键结论

1. **教师不合格**：均值 BA 0.6991，低于协议门槛 0.72 共 2.1 分。
2. **稳定性极好但水平不够**：seed 间 std 仅 0.0082（门槛 0.05），三个 seed 是
   0.7060 / 0.6876 / 0.7037 —— 说明模型**稳定地停在这个水平**，
   **加更多 seed 不会让均值上升**。这不是随机波动问题，是能力上限问题。
3. **项目此前记录的 0.7166 不可比**：那是「单 seed + 用验证集选最佳 epoch」的口径，
   含约 +1.8 分选择偏差。同一模型三种口径：
   | 口径 | BA |
   |---|---|
   | 单 seed 42 + 外层验证早停（项目记录） | 0.7166 |
   | 3 seed + 外层验证早停 | 0.6991 |
   | **3 seed + 泄漏安全嵌套 CV** | **0.6693** |
   **教师真实水平约 0.67。**
4. **蒸馏不得启动**：教师相对 Gen5 学生（同协议 0.6943~0.7359）的领先不足 1 分，
   而折间 std 是 ±0.04~0.05 —— 蒸馏收益落在噪声里，测不出来。
   > 📌 **2026-10-09 15:52 更新**：上句引用的 0.6943~0.7359 来自含 C10 泄漏的探针，已作废。
   > 按 RV-1 修复后口径重测（同一评估集 2890 窗）：**Teacher B 0.7130 vs Gen5 0.7232** ——
   > **学生反而高 1.0 分**。结论方向不变且更强：蒸馏仍不得启动。
   > 见 `artifacts/probes/_superseded/README.md` 与 `runs/20261009-155207_probe_rv1_matrix_2x2`。
