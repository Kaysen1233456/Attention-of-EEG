## 关键结论

### 一句话

**40 维频谱特征里各频带的真实信息量差异很大；gamma 的判别力可能来自 EMG 污染而非神经信号。**
但这只是 **n=2 的假设**，必须用全量嵌套 CV 验证后才能写进任何协议。

### 解决了两个事实性问题

**（1）官方 README 的「30 Hz 高通」说法是错的。**
README.txt 写 "A high-pass filter with a 30 Hz cut-off frequency" —— 若属实，
delta/theta/alpha/beta 全被滤掉，40 维里 32 维是垃圾，属灾难级问题。
**实测 EDF 头 prefiltering 字段（权威）：`HP:0.500000Hz LP:45.000000Hz RF:50Hz`。**
即 0.5 Hz 高通 + 45 Hz 低通 + 50 Hz 陷波。alpha 实测占 20–46% 功率也印证了这点。
→ **`preprocess_mental_arithmetic.py` 的 1–45 Hz 带通正确，特征构造无系统性错误。**

**（2）gamma 功率极低但无死维。**

| 频带 | 占 1–45 Hz 功率 |
|---|---|
| delta | 24.9% – 49.8% |
| theta | 11.8% – 19.5% |
| alpha | 14.1% – 46.3% |
| beta | 14.6% – 20.9% |
| **gamma** | **1.1% – 3.9%** |

40 维逐维 std 范围 `0.47 – 0.77`，**近似常数维 = 0 / 40**。
log(相对功率) 把 gamma 放大到了与其他频带同量级。

### ⚠️ 核心风险假设：gamma 的判别力可能是 EMG 污染

心算任务伴随皱眉/咬紧牙关，肌电能量正落在 30–45 Hz。
gamma 只占 1–4% 功率却是最强判别器，且判别力集中在 **Pz/P3/P4/T4**
（0.76/0.69/0.70/0.57）而非额叶认知负荷区 —— 更像颈/颌肌电容积传导。

**若成立，会导致「测试集虚高、部署失效」。**

验证方法：① 看 30–45 Hz 与 45–100 Hz 的功率斜率（EMG 宽带）；
② gamma 判别力的通道拓扑检验；③ 45 Hz 以上空载对照；④ 全量 36 被试复现。

> 初步观察：45–100 Hz 能量约 10⁰–10³，比 1–30 Hz 的 10⁵ 低 2–5 个数量级，
> **暂不支持强 EMG**，但需全量数据与更严格的检验。
> **验证完成前，不得声称 gamma 捕捉到了认知负荷。**

### 已知局限（引用必须带上）

1. **n=2**（本地仅 Subject00/01 的原始 EDF），只能产生假设
2. 分类器是**最近质心**（非训练模型），只用于频带间相对比较
3. 被试内设定，**无跨被试域偏移**，BA 偏高，不能与跨被试 ~0.70 直接比较
4. rest:focus = 91:31，多数类准确率 0.746，故全程只用 BA
5. 未做滤波/重参考/ICA，与预处理流程不完全一致

> **过程记录**：本审计第一版脚本用 `accuracy` 评估单频带可分性，得出
> 「delta 0.77 / alpha 0.71」等看似可用的数字 —— 但**几乎完全由多数类（0.746）决定**，
> 是无效结果。已改为 BA 并重跑。这正是本项目坚持用 BA 的原因，记录在此以防重犯。

### 是否改变后续计划

**不直接改变**，新增 3 条**待验证假设**（建议进 `INVALID_METHODS_REGISTRY.md` 的
